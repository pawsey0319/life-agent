# 安全边界与上线门禁

## 当前安全声明
本项目区分**领域策略测试通过**、**HTTP 真实请求通过**、**数据库防线验证通过**和**真实模型评测通过**。任一层不代表其他层。演示环境仅允许本机使用，不得输入私密数据。未完成数据库集成验收前，配置模式也不是面向真实用户的生产服务。

## 信任边界
1. Expo 客户端与模型输出都是不可信输入。用户、session、block、namespace 身份由 Runtime 验证和绑定；不采信请求体的身份声明。
2. 一个用户看不到另一用户的任何领域对象，包括导出、队列、待确认、图片和审计。浏览器不能拿到 service role、模型凭证、主加密密钥。
3. 专业 Agent 之间没有直接数据访问。字段注册表白名单与服务端授权网关决定是否读取；manifest 仅表达申请，不授予权限。
4. 外部响应只能作为带来源的不可信内容。文本不能触发工具、改变授权、执行代码或进入待执行指令队列。M0 不接入外部代理，不以字符串过滤冒充完整沙箱。

## 三类同意互不替代
- **敏感存储**：特定候选内容的记忆存储同意；修改内容重新评估。`remember` 不能跳过它。
- **跨积木共享**：绑定源、目的、字段、时段、用途及版本的授权；拒绝与允许都审计。禁止字段不能被授权覆盖。内部敏感长期仅从授权中心发起；外部敏感逐次。
- **读聊天原文**：仅 PA、单次、明确来源/时段/用途/会话，原子消费，不适用于普通长期授权。回复也可能泄漏原文，因此派生回复不进入记忆和以后模型上下文。

待同意记忆有 TTL，不能进入正式记忆检索/普通导出；拒绝/过期清除候选。源聊天记录是否保留是独立问题，不用“拒绝记忆”误导为“从所有历史中删除”。

## 记忆规则
核心记忆从自动夜间衰减、归档、合并和替换中排除；冲突先由用户确认。安全规则独立于语义检索。规则超过容量时提示并停止依赖不完整约束的建议，而不是静默截断后继续。

物理删除应覆盖内容、向量/关键词索引、待确认副本、模型缓存与导出中的活动副本。审计只记录删除对象 ID 和时间，不保留正文。已产生的备份按真实服务保留策略清除；文档不能承诺即时擦除第三方备份。

## 加密与持久化
配置模式对用户内容进行服务端信封加密，使用每用户 DEK，由主密钥包装，主密钥只在服务端。TLS 仍然必需；向量本身同样可能泄露语义，不能以“不是原文”豁免。

**当前配置适配器已改为逐实体加密 + 事务 CAS 修订号**：`runtime_entities` 是唯一活动数据源，`runtime_projection_state` 只存包裹密钥/版本，`runtime_audit_events` 只追加元数据。新事务 RPC 检查核心行的稳定 HMAC 指纹与保护元数据；核心内容、级别、状态变更/删除需要由本人操作路由注入明确动作，Worker 不携带此权限。读取解密后验证 HMAC、保护元数据及会话关系，再比较版本以拒绝混合快照。向量只留加密实体，不随 bootstrap/导出发送。

这仍不是已通过真实数据库验收的声明：新的逐实体表不等于原方案全部专用领域表，部分关系由事务 RPC 校验而非声明式外键；代码与 SQL 均需真实 Postgres 行为测试。旧版 `runtime_state` 不再用于活动读取；发现遗留聚合状态时拒绝并要求受控迁移，不自动信任旧密文重建核心权限。

CAS 冲突必须中止本次变更并重载，不允许静默覆盖较新状态；超时重试要有幂等性，队列不能用旧快照复活已删数据。多实例并发、崩溃恢复和消息/记忆原子性必须真实数据库压测。

## 必须执行的上线验收
- 不带 token、伪造 token、跨用户对象、跨命名空间逐端点拒绝；RLS 与服务端双层测试。
- 不同并发连接竞争单次授权，成功消费恰好一次；数据库事务与客户端重试验证。
- 夜间任务12个月模拟仍保留核心；数据库角色不能旁路触发器；授权过期/撤销立即失效。
- 新增 manifest 字段、端点/版本变更重新确认；暂停停止调用/摘要，卸载清理命名空间/授权/摘要。
- 删除记忆/聊天/积木/账号后，检索、导出、队列、索引和密钥处理验证。
- 配置 CORS 精确来源、TLS、请求大小/频率限制、代理策略、日志脱敏、主密钥备份与轮换。
- 真机验证通知只显示泛化提示，不含健康、消费或聊天正文；早报遵守用户 IANA 时区。
- 实际模型敏感漏报与专业路由评测。确定性测试不是自然语言零漏报的证明。

## 报告漏洞
不要在公开 issue 中上传聊天、身体照片、JWT 或密钥。先提供去标识化复现步骤、端点、角色与预期/实际行为；凭证疑似泄漏时先撤销再调查。
